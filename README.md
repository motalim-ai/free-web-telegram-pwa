# free-web-telegram-pwa

**فكرتك ← موقع + تطبيق داخل تيليجرام + تطبيق على الجوال، مجاناً بالكامل، وبمساعدة أي AI.**

تعطي رابط هذا الريبو لمساعد الذكاء الاصطناعي الذي تستخدمه، فيسألك عن فكرتك، ويكتب لك خطة توافق عليها، ثم يبنيها ويشغّلها على جهازك، ثم ينشرها على الإنترنت ويربطها ببوت تيليجرام خاص بك. أنت فقط تجيب عن أسئلته.

## ماذا ستحصل عليه

- 🌐 **موقع** يفتح من أي متصفح.
- 💬 **تطبيق داخل تيليجرام** (Mini App) من بوتك. يتعرف على العميل باسمه بدون تسجيل دخول.
- 📱 **تطبيق على الجوال** (PWA) يُثبّت على الشاشة الرئيسية، ويفتح حتى بدون إنترنت.
- 🧑‍💼 **لوحة تحكم** لك وحدك، تفتحها من تيليجرام بضغطة.
- 🔔 **إشعارات على تيليجرام** بكل طلب أو حجز جديد، مع أزرار تأكيد وإلغاء.

وكل ذلك من **نفس الكود ونفس الرابط**.

## مجاني فعلاً؟

| ماذا | أين | التكلفة |
|---|---|---|
| السيرفر والموقع | Cloudflare Workers | مجاناً (حوالي 100 ألف زيارة يومياً) |
| الرابط | `اسم-مشروعك.حسابك.workers.dev` | مجاناً |
| قاعدة البيانات | Cloudflare D1 | مجاناً |
| الصور | Cloudflare KV | مجاناً، بدون بطاقة بنكية |
| البوت والإشعارات | Telegram | مجاناً |
| مساعد الذكاء الاصطناعي | يمكن استخدام أدوات مجانية (انظر بالأسفل) | مجاناً أو اشتراكك الحالي |

الدومين الخاص (مثل `.com`) اختياري وليس مجانياً (حوالي 10 دولارات سنوياً). والدفع بالبطاقة أونلاين يحتاج حساب تاجر، لذلك يأتي التطبيق بالدفع عند الاستلام والتحويل البنكي.

## طريقة الاستخدام (3 خطوات)

**1. حمّل الريبو وافتح مساعدك داخله:**

```bash
git clone https://github.com/motalim-ai/free-web-telegram-pwa.git
cd free-web-telegram-pwa
```

**2. اكتب لمساعد الذكاء الاصطناعي جملة واحدة:**

```
اقرأ ملف AGENTS.md في هذا الريبو وابدأ معي
```

**3. أجب عن أسئلته.** سيسألك عن فكرتك، ويعرض عليك خطة، ويطلب موافقتك قبل كل خطوة مهمة.

## أي AI يصلح؟

أي مساعد **يقرأ الملفات ويشغّل أوامر في التيرمنال**، مثل: Claude Code، Codex، OpenCode، Gemini CLI، Cursor.

المساعدات التي تعمل في المتصفح فقط (محادثة بدون تيرمنال) لا تستطيع التشغيل والنشر.

**سير عمل مجاني بالكامل:** استخدم **OpenCode** أو **Gemini CLI** مع نموذج مجاني. التعليمات في هذا الريبو مكتوبة خطوة بخطوة لتعمل حتى مع النماذج الأضعف.

## ماذا تحتاج قبل البدء

- **Node.js 20** أو أحدث، و**git**.
- حساب **تيليجرام**.
- بريد إلكتروني لإنشاء حساب **Cloudflare** مجاني (سيرسل لك المساعد الرابط).

لا تحتاج أي خبرة برمجية.

## محتوى الريبو

| المسار | المحتوى |
|---|---|
| `AGENTS.md` | تعليمات المساعد: كل مرحلة، ومتى يسأل، ومتى ينتظر موافقتك |
| `docs/` | تفاصيل كل مرحلة: الفكرة، الحسابات، البناء، المراجعة، النشر |
| `template/` | تطبيق كامل جاهز (متجر تجريبي) يبني عليه المساعد فكرتك |
| `projects/` | هنا يُنشئ المساعد مشروعك (لا يُرفع مع الريبو) |

## الأمان

- توكن البوت لا يُرسل في المحادثة أبداً، بل يُحفظ في ملف على جهازك فقط.
- الدخول بتيليجرام يتم التحقق منه في السيرفر بتوقيع تيليجرام نفسه.
- الأسعار والمجاميع تُحسب في السيرفر، فلا يمكن التلاعب بها من المتصفح.
- لوحة التحكم لصاحب المشروع فقط.
